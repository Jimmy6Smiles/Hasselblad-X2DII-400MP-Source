# 公共运行时与 MOD 开发规则

2026-10-21 用户确认。本规则取代历史独占包的启动配置所有权设计；不取消事务、身份校验或人工重启要求。

1. 安装器独立管理公共运行时及原厂启动配置的唯一接入点。公共组件不属于任何功能 MOD。
2. 四亿、多重曝光及后续 MOD 只提供自身程序、资源和声明式登记；不得携带或写入原厂启动配置，不得替换公共宿主或另一个 MOD 的文件。
3. MOD 声明公共 ABI 和兼容版本范围。安装器检查依赖；缺少运行时或版本不兼容时，进入独立公共组件安装/升级事务，或拒绝安装。不得通过功能包隐式覆盖公共组件。
4. 公共运行时按经过校验的登记加载功能。后台服务也通过登记声明，不执行包内任意安装脚本。
5. 同版本公共组件内容一致才可复用；内容不同拒绝覆盖。升级必须兼容全部已登记 MOD，禁止静默降级。
6. 卸载功能先撤销登记，重启证明模块不再映射后只清理其自有文件。公共运行时独立卸载，仍有依赖时禁止移除。
7. 单模块初始化失败不得阻止其他可用模块加载。共享采集服务的停止与恢复由公共层协调，功能模块不得自行停止整个采集服务。共享进程内的内存崩溃不等于已实现硬隔离。
8. 验收区分离线测试、实机启动、完整拍摄、安装顺序、独立卸载和故障恢复；不能互相替代。测试候选不标为发布完成。

## 当前进度与发布边界

公共运行时 1.0.8、四亿 1.2.4-rc4/revision-2、多重曝光 0.1.0/revision-7 的实机组合已完成两种安装顺序与分别卸载后拍摄验证。最后一组多重曝光的整张、放大、拖动也获用户确认。

故障隔离完整验收及 rc4 正式打包尚未完成。安装器图形界面和旧包入口仍需按本规则统一，不能把开发命令行入口视为最终用户安装流程。

当前构建脚本仍依赖开发工作区 `private-analysis/multiple-exposure` 下的 GUI 协调器、相册插件及多重曝光适配源文件。该依赖尚未全部归档到本库，当前提交是开发进度备份，不保证新克隆环境独立复现。后续应将必要源码与来源清单纳入本库，不带入照片、设备日志、密钥、全量固件或测试缓存。

既有稳定图像处理、封装算法保持不变；本次规则调整针对加载、登记和安装所有权，不以旧功能代码替换已验收实现。
